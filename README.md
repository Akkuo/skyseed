# SKYSEED 種子遠航

操控一顆蒲公英種子，在程式產生的無限 3D 大地上滑翔。乘著閃爍的上升氣柱與光絲風帶，飛越 **草原 → 河谷 → 舊城屋頂 → 秋林 → 雪嶺** 循環的五種生態，收集花粉維持生命力，降落在發光的肥沃地塊種出 8 片花海。

線上遊玩：https://akkuo.github.io/skyseed/

## 操作

| 動作 | 鍵盤 | 觸控 |
|---|---|---|
| 轉向（偏航） | `A` `D` / `←` `→` | 左側搖桿左右 |
| 壓低機頭／抬頭（俯仰） | `W` / `↑` 壓低，`S` / `↓` 抬頭 | 搖桿上推／下拉 |
| 張傘（減速、在氣流中加倍上升、可小半徑盤旋） | `Space`（按住） | 「張傘」按住 |
| 俯衝 | `Shift`（按住） | 「俯衝」按住 |
| 切換視角（追尾／遠景電影／第一人稱） | `C` | 「視角」 |
| 暫停 | `P` / `Esc` | 「暫停」 |
| 靜音 | `M` | 「音效」 |
| 開始／重新開始 | `Enter` / `Space` / 點擊；暫停或結束時 `R` | 點擊 |

標題與暫停畫面可勾選「減少晃動」（固定 FOV、鏡頭不翻滾、撞擊不震動），設定存在 `localStorage`。

## 玩法

- **生命力**隨時間流失（陣雨時更快）；花粉 +6、種出花海 +30、撞到地面或屋頂 −15。
- **上升氣流**：金色閃爍氣柱，進入後上升；張傘時升力 ×1.9。
- **風帶**：三股交纏的光絲緞帶，順著它飛會加速並被輕輕吸附在緞帶高度。
- **肥沃地塊**：地面上的發光圓環與光柱；觸地即種下花海，種子重新彈射升空。HUD 中央箭頭指向最近的地塊。
- **日夜**：約 3.5 分鐘一輪；夜晚有星空與螢火蟲。**陣雨**偶發，下沉加快、能見度降低。
- 目標：種出 8 片花海。分數 = 花海 ×100 + 花粉 ×5 + 航程 / 10。

## 技術重點

- Three.js r170（CDN importmap，版本釘死），原生 ES modules，無建置步驟；零外部素材（幾何、材質、音效全部程式產生）。
- `src/world.js`：種子化 Simplex noise 地形函數；生態依旅程軸（−Z）每 640 單位切換，交界處平滑混合高度與顏色。
- `src/terrain.js`：72×72 分塊、半徑 3 的無限地形，依距離排程每幀最多建 1 塊、遠塊回收並釋放 GPU 資源；每塊的裝飾（樹、房屋、蘆葦、岩石）合併成單一頂點色幾何，一塊只需約 2 次 draw call。
- `src/features.js`：氣柱、風帶、地塊光環以自寫 shader 動畫（加法混合、遠近淡出）；花海用 InstancedMesh 逐朵長出。
- `src/weather.js`：漸層天空穹頂、日夜光照與霧色、星空、螢火蟲、雨絲。
- `src/camera.js`：三種視角，位置／注視點指數平滑、翻滾角上限、FOV 緩變（防暈）。
- `src/audio.js`：Web Audio 合成風聲、雨聲、依生態切換音階的生成式 BGM 與音效。
- 自適應解析度：持續低於 28 FPS 時自動降低渲染比例。
- 測試介面：`window.__debug()`、`window.__start()`、`?autostart=1`。
